## 1. Design Principles

1. **데이터 밀도 우선** — 한 화면에 가능한 많은 정보. 카드보다 표.
2. **키보드 우선** — 모든 입력은 마우스 없이 가능. Tab/Enter/Esc 표준.
3. **상태는 배지로** — 텍스트보다 색·아이콘으로 즉시 인지.
4. **수동/자동 구분** — 자동 입력값은 회색 배경 + i, 수동 수정은 노란 배경 + 배지.
5. **모바일은 조회만** — 입력·일괄수정은 데스크톱 전용.
6. **세무 신뢰성** — 증빙·짝맞춤·확정 여부를 항상 가시화.
7. **되돌릴 수 없는 액션은 한 번 더 확인** — 정산 LOCK·정책 deprecate·REOPEN 등.

## 3. 디자인 시스템 컴포넌트

### 3-1. Layout

- **AppShell**: 상단 헤더(72px) + 좌측 사이드바 + 본문
- **Header**: 좌측 로고+조직명, 중앙 글로벌 검색(Cmd/Ctrl+K), 우측 알림 종, 사용자 메뉴
- **Sidebar**: IA 11개 1차 메뉴. 각 메뉴 우측 키보드 단축키 표시
- **Breadcrumb**: 본문 상단. "정산 / 월별 / 2026-06"
- **PageHeader**: 페이지 제목 + 보조 액션 버튼

### 3-2. Table (가장 중요한 컴포넌트)

- 헤더: sticky, 정렬 화살표, 너비 드래그
- 셀: 인라인 편집 가능 표시 (포커스 시 outline)
- 키 바인딩 (D-112):
  - `Enter` 저장
  - `Esc` 취소
  - `Tab` 다음 셀 / `Shift+Tab` 이전 셀
  - 방향키로 셀 이동
  - `Space` 행 선택
  - `Cmd/Ctrl+A` 전체 선택
- 일괄 선택 + 액션바: 선택된 행 N개 → "카테고리 일괄변경", "증빙상태 일괄변경", "삭제"
- 행 우측 점3개 메뉴: 상세 / 복사 / 삭제 / 감사로그 보기
- 페이지네이션: 하단. 50/100/200 선택. cursor 기반.

### 3-3. Form

- Vertical 또는 2-col grid
- 필수 필드 좌측에 *
- 자동 적용값: 배경 muted + 우측 `i` 아이콘
  - `i` 호버 시 팝오버: 정책 출처, version, source_type, source_checked_at, reliability_status
- 수동 수정 시: 배경 warn + 우측 "수동 수정됨" 배지 + 사유 입력(선택)
- 금액 입력: 천 단위 콤마 자동, 우측 정렬, 단위 "원"
- 비율 입력: % 단위 (12.5 → 0.1250 저장)
- 날짜: 캘린더 popover, 한국 로케일

### 3-4. Badge

| 배지 | 색 | 의미 |
|---|---|---|
| `CONFIRMED` | success | 정책 확정 / 정산 CONFIRMED |
| `AUTO_DETECTED` | info | 자동 감지 정책 |
| `NEEDS_REVIEW` | warning | 검토 필요 |
| `EXPIRED` | danger | 효력 만료 |
| `MANUAL_OVERRIDE` | warn 배경 + warning 텍스트 | 수동 수정됨 |
| `DEPRECATED` | gray | 폐기 |
| `DRAFT` | gray | 정산 임시 |
| `LOCKED` | locked 배경 + 자물쇠 아이콘 | 잠김 |
| `REOPENED` | danger | 재개 (audit 동반) |
| `증빙없음` | danger | |
| `확인필요` | warning | |
| `증빙있음` | info | |
| `전달완료` | success | |

### 3-5. Modal & Drawer

- **Modal**: 짧은 확인·작은 폼 (1열 240px+). 예: 정책 신규 버전 등록
- **Drawer (우측)**: 상세 보기 + 편집 (상품 상세, 비용 상세). 540px
- **Confirm Dialog**: 되돌릴 수 없는 액션. 사유 입력 필수

### 3-6. Toast

- 우상단. 성공(녹색), 경고(노란), 에러(빨강). 5s 자동 dismiss. 작업 결과 1줄.

### 3-7. Empty / Loading / Error

- 빈 상태: 아이콘 + 1줄 설명 + 1차 액션 버튼
- 로딩: skeleton (표 행 모양 유지)
- 에러: 박스 + 재시도 버튼 + "지원팀에 문의"

### 3-8. 정책 자동값 마이크로 인터랙션 (핵심)

## 5. 인터랙션 패턴 (요약)

### 5-1. 인라인 편집
- 셀 클릭 또는 Tab → 편집 모드
- Enter → 저장 (즉시 API patch)
- Esc → 취소
- 실패 시 셀이 빨간 outline + 토스트

### 5-2. 일괄 수정
- 체크박스 다중 선택 → 액션바 등장
- "카테고리 일괄변경" → 모달에서 단일 값 선택 → 적용

### 5-3. 정책 자동값
- 자동 적용 시 회색 + ⓘ
- 수정 시 노란 + 배지 + 사유 입력 (선택)
- 정책이 NEEDS_REVIEW/EXPIRED 면 상단 노란 배너

### 5-4. 확정/잠금
- DRAFT → CONFIRMED: 1단계 확인
- CONFIRMED → LOCKED: 2단계 확인 (잠금 후 수정 불가 안내)
- LOCKED → REOPENED: 사유 필수 + 2단계 확인 + 알림 발송

### 5-5. 키보드 단축키 (전역)

| 키 | 동작 |
|---|---|
| Cmd/Ctrl + K | 글로벌 검색 |
| G + D | 대시보드 |
| G + S | 판매장부 |
| G + E | 사업비용 |
| G + M | 마진계산기 |
| G + R | 리포트 |
| ? | 단축키 도움말 |
