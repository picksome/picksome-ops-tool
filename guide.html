Next.js 15 FastAPI PostgreSQL Asia/Seoul KRW 기준

소개 및 개요

PICKSOME OPS TOOL은 기존 마진계산기&장부.xlsx를 대체하는 셀러 운영 SaaS입니다. 상품 소싱 → 마진 계산 → 판매 장부 → 사업비용 → 월별 정산 → 파트너 수익배분 → 세무 리포트까지 운영의 전 과정을 하나의 시스템에서 관리합니다.

🧮 마진 계산

마켓 수수료, 결제 수수료, 부가세, 풀필먼트, 반품 위험비율을 정책 테이블에서 자동 적용해 예상/실 마진을 계산합니다.

📊 월별 정산

매출 − 직접비 − 사업비용 = 순이익 공식으로 월별 정산을 계산하고, 파트너 비율대로 수익을 배분합니다.

📋 세무 리포트

월별 매출·매입, 판매처별 매출, 상품별 손익, 부가세, 증빙 누락 등 9종 Excel 리포트를 생성합니다.

MVP 범위: 수동 입력 + Excel Import/Export 기준입니다. 쿠팡/스마트스토어 API 연동, 야간 배치, 가격 알림은 Post-MVP 예정입니다.

로그인

이메일과 비밀번호로 로그인합니다. 로그인 후 Access Token이 발급되며 브라우저 로컬 스토리지에 저장됩니다. 토큰 만료 시 자동 갱신됩니다.

정산 순이익 계산 공식

순이익 = 총매출
      − 상품 직접비 (원가 + 마켓수수료 + 광고비 + 반품비 + 풀필먼트 + 배송비)
      − 사업 공통비 (expenses 월별 합계)

분배가능 = 순이익 − 이월 누적 손실

정산 상태 흐름

DRAFT 임시 → 계산 후 CONFIRMED 확정 → 최종 잠금 LOCKED 잠김 🔒 → 수정 필요 시 REOPENED 재개
LOCKED 후 변경 불가: 잠금 상태에서는 정산 내용을 수정할 수 없습니다. 수정이 필요하면 REOPEN(재개) 처리가 필요하며, 조직별 기본 최대 3회까지 가능합니다.

월간 운영 플로우

매월 반복하는 표준 운영 순서입니다.

  1. 상품/판매 데이터 입력

    상품 관리에서 신규 상품 등록, 판매 장부에 매출 데이터 입력. 옵션/Variant는 상품별로 설정.

  2. 사업비용 등록

    이번 달 발생한 광고비, 배송비, 수수료 등을 전부 expenses에 등록. 영수증 등 증빙 상태도 함께 기록.

  3. 증빙 확인

    사업비용 → 증빙 탭에서 "증빙없음" 0건이 될 때까지 확인. 세무사 제출 전 필수.

  4. 월별 정산 계산

    월별 정산 → "이번달 계산" 버튼 클릭. 순이익과 파트너 배분액이 자동 계산됨.

  5. 정산 확정 → 잠금

    계산 결과 검토 후 CONFIRMED → LOCKED. 잠금 후에는 수정 불가.

  6. 세무 리포트 다운로드

    세무 리포트 메뉴에서 기준 월 선택 후 필요 리포트 Excel 다운로드. 세무사에게 전달.

권장 마감 일정: 전월 말일까지 사업비용 입력 완료 → 익월 1~5일 내 정산 계산/확정 → 익월 10일 전 세무사 제출.

FAQ

Q. 정산을 LOCKED 후 실수로 수정이 필요하면?

정산 상세 페이지에서 REOPEN 버튼을 누르면 REOPENED 상태로 전환됩니다. 단, 조직별 최대 3회까지만 가능합니다. 재개 횟수를 모두 소진하면 관리자에게 문의하세요.

Q. 마진 계산 시 수수료율이 잘못된 것 같으면?

설정 → 정책 관리 → 마켓 수수료 정책에서 현재 적용 중인 값을 확인하세요. 신뢰도가 "검토 필요"인 항목은 실제 수수료율과 다를 수 있습니다. 관리자가 수정하면 이후 계산부터 자동 반영됩니다.

Q. 적자월이 발생했는데 다음 달 배분은?

적자액은 자동으로 이월(carryover)됩니다. 다음 흑자월 분배 전 이월 손실을 먼저 차감합니다. 대시보드 "분배 가능 순이익" 카드의 서브텍스트에서 이월 반영 여부를 확인할 수 있습니다.

Q. 세무 리포트가 세무 신고를 대신하나요?

아닙니다. 이 시스템은 세무사가 신고에 사용할 수 있는 구조화된 참고 자료를 제공합니다. 실제 신고는 반드시 세무사가 검토 후 처리해야 합니다.

Q. Automation 메뉴가 비활성화되어 있어요.

Import, Export, Batch Jobs, Integration Logs는 Post-MVP 기능으로, 현재 버전에서는 사용할 수 없습니다. 향후 쿠팡/스마트스토어 API 연동과 함께 활성화될 예정입니다.

Q. 새 사용자를 추가하려면?

현재 MVP에서는 사용자 초대 기능이 없습니다. 관리자가 직접 계정을 생성한 후 설정 → 사용자/권한 메뉴에서 역할을 부여하세요.
