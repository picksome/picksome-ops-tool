1 Vision & Goal

🚀

1차 목표 (MVP)

픽썸 내부 운영 SaaS

  • 엑셀 마진계산기&장부 프로세스 프로그램화
  • 마진계산·판매장부·사업비용
  • 월별정산·세무사 제출용 리포트 자동화
🌐

최종 목표 (Post-MVP)

범용 셀러 운영 자동화 SaaS

  • 다른 셀러도 사용 가능
  • 마켓 정산·공급처 가격 자동 수집
  • 정책값 자동 감지 + 관리자 승인
  • 세무사 협업 모드
🚫

비목표 (Out of Scope)

절대 포함하지 않음

  • 세무 신고 자동 대체
  • 판매 사이트 자체 운영
  • 결제 모듈

5 RBAC — 6개 역할

ADMIN
관리자
전체 권한. 사용자 관리, 정책 승인
OPERATOR
운영 담당자
상품·판매장부·마진계산 입력/수정
SOURCING
상품 소싱
소싱 후보·상품 등록
ACCOUNTING
회계/세무
사업비용·정산·세무 리포트
READONLY
읽기 전용
대시보드·장부·정산 조회
EXTERNAL
외부 세무사
읽기 + 코멘트 + 증빙상태 변경
⚠️ 중요: MVP에서 화면을 다 안 만들어도 DB·서비스 계층은 role 기반 접근제어가 동작해야 한다.

11 사용자 결정 필요 (Open Items)

  2. 알림 채널 우선순위: 이메일만(MVP) vs 카카오톡/슬랙 동시

  5. 공급가액/부가세 자동 분리 정책: total만 입력 시 자동 분할 적용?
  6. 정산 REOPENED 횟수 제한: 무제한 vs N회 제한
  7. product 옵션 슬롯 사전 준비 여부: Post-MVP라도 DB에 컬럼 미리 둘까
